# Search All Functions - Major Zoho CRM DevTools Update

Date: 2026-07-04
Channels: Reddit

## Post

Subject: Search All Deluge Functions - Major Zoho CRM DevTools Update

Hello everyone,

We've released Search All Functions, a new feature for the Zoho CRM DevTools extension.

A "Search All Functions" button is now available on Zoho CRM's functions page. It opens a dashboard that searches every Deluge function in your org at once, covering names, API names, descriptions, and full source code. Selecting a result and choosing "Edit in CRM" opens it directly in Zoho's native editor.

Previously, locating where a specific field API name, module, webhook, or piece of legacy logic is used across an org meant opening functions one by one. This feature reduces that to a single search.

It's free, like everything we've released so far.

The extension is available on the Chrome Web Store:
