# Search all functions in Zoho CRM

Date: 2026-09-09
Channel: Admins Zoho User Group
Post: https://www.zohocommunity.com/zcs/stream/93270000012102033

## Post

Hi everyone,

We've added Search All Functions to Zoho CRM DevTools.

It gives you one place to search every custom function in your CRM org by keyword. Search for a
service name (e.g. Mailchimp or Books), a field API name (e.g. Lead_Source), part of an endpoint,
or anything else. It checks function names, API names, descriptions, and Deluge code. You can
preview the results and open any match in CRM's native editor.

It's useful for debugging, reviewing automation, and understanding an existing CRM setup without
opening functions one by one.

Zoho CRM DevTools is free and open source.

If you use it and find something missing, let us know.
