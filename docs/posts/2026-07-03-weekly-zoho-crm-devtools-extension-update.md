Subject: Weekly Zoho CRM DevTools Extension Update

Hey everyone!

This week we shipped a bug fix for the Deluge editor cursor behavior.

Our custom syntax highlighting could sometimes make cursor movement feel weird on certain lines. That is fixed now, so the editor should feel native again while keeping the cleaner themes, better highlighting, and indent guides.

A quick spoiler about the next update: Search All Functions.

You'll be able to search across all Zoho CRM functions from one place, including names, API names, descriptions, and Deluge source code. Very useful when you need to find where a field API name, module, webhook, or old logic is used.
