# 0003 Marketing Channels

## Decision

Post weekly update posts to Reddit only. Do not open a new Zoho Forum topic for every update.

## Rationale

The Zoho Forum moderation team asked us not to start a new topic on every release. Reddit has no such
restriction, so it remains the primary channel for update posts. Existing Zoho Forum threads can still
be used for support replies; only new per-update topics are affected.
