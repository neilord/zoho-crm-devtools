# Roadmap

## Milestone 1: Foundation

- Project scaffolding
- Tooling
- Docs
- Minimal popup
- Storage and feature registry

## Milestone 2: Live Debug Loop

- Verify extension reload workflow
- Capture Zoho editor/settings fixtures
- Document selector discovery

## Milestone 3: First Feature Slice

- Inject one custom theme option into Zoho's native theme picklist
- Preserve selection and reopen behavior

## Milestone 4: Editor MVP

- Theme registry
- Font controls
- Ligatures and italics
- Indent guides
- Practical syntax enhancement

## Milestone 5: Cross-Function Search (free)

- "Search Functions" control on the Zoho functions page
- Search overlay across all org Deluge functions, including source
- Function detail view with "Edit in CRM" handoff to Zoho's native editor

## Later Ideas

- GitHub sync
- Bulk import/export (function export/backup, potential premium home)
- Client-script search and failure logs (deferred from the original tool)
- Firefox support
