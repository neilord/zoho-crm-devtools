# Changelog

## 2.2.0 - 2026-07-15

- Added Deluge syntax highlighting to the Search All Functions code preview, colored to match
  Zoho's native light Deluge editor. The searched term stays highlighted on top of the coloring.

## 2.1.0 - 2026-07-04

- Added cross-function search: a "Search All Functions" control on the Zoho functions
  page opens an overlay to search every Deluge function in the org, including source,
  with an "Edit in CRM" handoff to Zoho's native editor.

## 2.0.1 - 2026-06-27

- Fixed a cursor positioning bug in highlighted Deluge code.

## 2.0.0 - 2026-05-27

- Published the current Chrome Web Store release.
- Added custom editor themes for the Zoho CRM Deluge editor.
- Added indent guides.
- Added practical Deluge syntax highlighting improvements.
- Added a minimal popup with an enable/disable switch.

## Notes

This project keeps user-facing free features free. Future premium features, if added, should be new additive features rather than existing free features moved behind a paywall.
