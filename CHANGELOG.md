# Changelog

## 2.4.0 - 2026-10-25

- Added Search All Workflows on Setup › Workflow Rules: search criteria, actions, field updates
  and linked functions across every rule. Included in every paid plan.
- Added Automation Map (Beta): see how workflow rules, field updates and functions connect on one
  zoomable map. Included in Pro and Max.
- Added a one-time "What's new" card introducing these tools. It stays until you click Got it,
  close it, or open one of its links.
- Added optional account sign-in in a browser tab. All existing features stay free forever,
  with no account required.
- Added Paid Export functions beside Search All Functions: download your org's functions locally
  as JSON, CSV or Markdown. Start a 14-day free Plus trial, no card required. Plus is $9 for the
  first paid month, then $23/month; Pro is $35 first month, then $57/month; Max is $99 first month,
  then $143/month. The first-month price applies only to an account’s first-ever paid subscription,
  never to plan changes or repeat subscriptions.
- Added a one-time account/privacy notice for existing users. Zoho data stays on your device;
  payments are handled through Stripe on our website.

## 2.3.0 - 2026-09-18

- Added a one-time corner card introducing Zoho CRM AI Assistant, our new companion extension,
  with its icon and a small preview of the side panel. It appears once on a Zoho CRM page, can be snoozed for three days a single time, and never
  returns after Install or Close. No new permissions.

## 2.2.1 - 2026-09-16

- Kept Search All Functions easy to find in Zoho's new Functions layout by placing it immediately
  beside the native Search field. The existing placement remains unchanged in the previous layout.

## 2.2.0 - 2026-07-15

- Added Deluge syntax highlighting to the Search All Functions code preview, colored to match
  Zoho's native light Deluge editor. The searched term stays highlighted on top of the coloring.

## 2.1.0 - 2026-07-04

- Added cross-function search: a "Search All Functions" control on the Zoho functions
  page opens an overlay to search every Deluge function in the org, including source,
  with an "Edit in CRM" handoff to Zoho's native editor.

## 2.0.1 - 2026-06-27

- Fixed a cursor positioning bug in highlighted Deluge code.

## 2.0.0 - 2026-05-27

- Published the current Chrome Web Store release.
- Added custom editor themes for the Zoho CRM Deluge editor.
- Added indent guides.
- Added practical Deluge syntax highlighting improvements.
- Added a minimal popup with an enable/disable switch.

## Notes

This project keeps user-facing free features free. Future premium features, if added, should be new additive features rather than existing free features moved behind a paywall.
